# 243-4J5 — LoRa et LLM (semaines 9 à 12)

Code de départ du cours 243-4J5-LI – Objets connectés, Cégep Limoilou. Le matériel du cours est sur le [site du cours](https://4j5.ve2fpd.com/).

| Dossier | Utilisation |
|---------|-------------|
| `labo-04/` | Appel d'un LLM depuis l'ESP32 |
| `tp-lora-llm/` | Votre TP évalué : liaison LoRa, analyse LLM et MQTT |

## Démarrer

1. Cliquez sur **Fork** pour créer votre copie. Un fork d'un dépôt public reste public.
2. Clonez votre fork, puis copiez `config.example.h` vers `config.h`.

**Ne publiez jamais vos clés d'API.** Le fichier `config.h` est ignoré par Git : vérifiez `git status` avant chaque commit.
